# Manim Studio 0.3.0 (proposed)

**Status:** prepared, not released. A git tag, any push and any publication are the
maintainer's decision (ADR 0045). Nothing has been tagged, pushed or uploaded.

0.1.0 rendered a project file to a video from the command line. 0.3.0 is the first version
with the editor: a visual, timeline-based studio built on Manim Community 0.22, where what
you see on the canvas is exactly what Manim renders. (There was no 0.2.0 release: the numbers
moved on while the editor grew.)

## Install

Requirements:
- Python 3.13
- [uv](https://docs.astral.sh/uv/)
- a LaTeX distribution, needed for equations: [MiKTeX](https://miktex.org/) on Windows, or
  TeX Live. Without one, equations are drawn as a dashed placeholder and the status bar says
  "LaTeX is not installed"; everything else keeps working.

FFmpeg comes with the PyAV package; nothing else needs installing by hand.

```bash
uv tool install manim_studio-0.3.0-py3-none-any.whl
manim-studio edit
```

`manim-studio --version` prints the versions of Manim Studio, Manim and Python.
`manim-studio render project.json out.mp4` renders without the editor.

## What's new

### Build a scene
- **Objects:** shapes (including a **right triangle** with a base and an acute angle), text,
  LaTeX (`MathTex`, `Tex`), counting numbers, images, SVG drawings, axes with function graphs,
  points, areas and Riemann rectangles on them. There are also connectors that follow two
  objects, traced paths, and code layers that run a Manim scene of your own.
- **Equations:**
  - Turn the terms of an equation into **parts**, each animated as its own layer, and
    **colour a part** without making a separate object (Properties > "Colour a part").
  - Colour pieces of a plain text too ("Colour a piece").
  - Morph one equation into another with TransformMatchingTex.
- **Groups:** Edit > Group (Ctrl+G) and Ungroup (Ctrl+Shift+G). A group moves, scales, turns
  and fades its objects together; the objects keep their own clips and keys.
- **On the canvas:**
  - Select, move, scale and rotate objects, and move their anchor.
  - Drag round handles to change sizes, line ends and text size.
  - Moves snap to other objects and to the frame, with guides.
  - Select several objects with Shift+click or a rectangle.
  - **Arrange** aligns and distributes the selection.
  - Zoom and pan the canvas; **F** frames the selection (the whole frame when nothing is
    selected).
- **Presets, themes and templates:**
  - 32 built-in animation presets, applied to every selected layer at the playhead and
    browsable with live thumbnails (Animate > Browse Presets).
  - 5 colour themes.
  - 6 templates.
  - Save your own presets and templates.
- **The scene itself:** with nothing selected, Properties shows the scene - its length, size,
  frame rate, background and a **camera** (tilt, turn, roll; the default is the flat view
  every earlier project uses). The scene grows by itself when you place something past its
  end; Fit Length to Content trims it.

### Animate
- **The timeline:**
  - Clips (Create, Write, FadeIn, Transform, MoveAlongPath, Indicate and more) are moved and
    trimmed with snapping.
  - Each object's row expands into one row per property (position, scale, rotation,
    opacity), with its value at the playhead and a diamond to key or unkey it; keys are
    dragged, eased and deleted one property at a time.
  - **Select several** clips and keys (Shift/Ctrl+click, a rectangle, Ctrl+A) and drag them
    together; drag a selected row's band to move whole layers; Edit > Shift Timing moves
    the selection by a number of seconds. A moved first or last clip takes its "Appears at" /
    "Disappears at" along.
  - **Follow Playhead** keeps the playhead in view; the scene's end is a line to drag on the
    ruler; markers are added with M.
  - It has a subtitles row and sound rows with waveforms, and opens fitted to the whole
    scene.
- **Keyframes:**
  - Transform properties carry keyframes, with a stopwatch per property, Record (Auto-key) and
    curves for the properties you choose in the graph.
  - Auto-key places a new object instead of keying its start; it animates once the object
    has an entrance.
  - Eases include a curve editor.
  - Position paths can be curved and are edited on the canvas.
- **Simulated layers** step a physics simulation frame by frame. Plugins can add their own.

### Workspace pages, like DaVinci Resolve's
- **Compose:** the layers, the canvas over the timeline, and Properties.
- **Animate:** a graph editor of the chosen properties' keys.
- **Code:** an editor for code layers, with highlighting and errors shown at their line;
  code layers are renamed and deleted from the list.
- **Audio:** tables of sounds and subtitles, and a level meter.
- **Deliver:** render settings (size, fps, range, quality, subtitles), a render queue, and
  the Python export.
- Switch pages with Shift+1 to Shift+5. The panel sizes of each page are remembered.

### Sound and subtitles
- Import audio, set gains and fades, and play back in sync.
- Subtitles can be edited, imported or exported as `.srt`, and burned into the video.

### Export
- Export an MP4 at any size, fps and range, in the background, with the sound.
- Export a Python scene: readable plain Manim code (now also for keyframed objects, and
  every built-in preset), or an exact replay.

### Working comfortably
- **Undo and history:** undo for everything, and cut, copy, paste and duplicate (layers,
  clips, sounds, subtitles).
- **Recovery:** crash recovery copies of unsaved work.
- **Speed:** frames are rendered ahead of the playhead in a second process, so playback and
  scrubbing stay smooth; scenes of 15 minutes and 300 layers stay responsive.
- **Preferences and help:**
  - The editor remembers recent files, the window, panel sizes, view toggles and the last
    page.
  - A welcome screen offers New, Open and the example.
  - Help > Keyboard Shortcuts (F1) lists every shortcut; Help > Open Log Folder opens the log.
- **Look:** a dark studio theme with measured text contrast and Phosphor icons.

## Upgrading from 0.1.0

- Project files keep `schema_version` 1. A 0.1.0 project opens as it is; the new fields
  (camera, groups, part colour, "grow with content") are left out of a file unless used.
- Preferences are stored in `manim-studio.ini` in the user configuration folder. Delete that
  file to reset them.
- Your own presets and templates go in the user library folder
  (`MANIM_STUDIO_LIBRARY` overrides it).

## Known limits

- Equations need a LaTeX installation to be drawn (see Install).
- There is no standalone installer yet; the package needs Python 3.13.
- Parameters such as a rectangle's width are not keyable. Size handles change the object for
  its whole life.
- A queued render is lost when the editor quits.
- Groups carry a transform only: no clips on a group, no nested groups, and no morphs across
  a group's edge. A project with groups, or with coloured equation parts, exports its Python
  scene in the exact (replay) form.
- With the camera turned, the canvas shows the picture but not selection outlines or
  handles, and ignores clicks; select in the Layers list.
- 3D objects are not part of this version; the camera only views the flat scene from an
  angle.
