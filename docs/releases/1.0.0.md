# Manim Studio 1.0.0 (proposed)

**Status:** prepared, not released. The version number in `pyproject.toml`, a git tag, any push and any
publication are the maintainer's decision ([ADR 0045](../adr/0045-releases.md)). Nothing has been tagged,
pushed or uploaded, and `pyproject.toml` still says 0.3.0.

1.0.0 is the first version with a promise attached: **project files stay readable**. `schema_version` 1 is
frozen, new fields are only ever optional, and a breaking change would bump the version and ship a migration
([project format](../project-format.md#compatibility)). Everything in [0.3.0](0.3.0.md) - the editor, the five
pages, equations, code layers, presets, sound, subtitles, export - is part of 1.0.0; there was no published 0.3.0,
so this is the first release of the editor.

## Install

Requirements are the same as 0.3.0: Python 3.13, [uv](https://docs.astral.sh/uv/) and a LaTeX distribution
for equations ([MiKTeX](https://miktex.org/) on Windows, or TeX Live). FFmpeg comes with the PyAV package.

```bash
uv tool install manim_studio-1.0.0-py3-none-any.whl
manim-studio edit
```

## What is new since 0.3.0

### A new interface: Lumen
- **Lumen** ([design](../design/lumen.md), [ADR 0063](../adr/0063-lumen-interface.md)): soft cards around the
  picture, one accent, a top bar with the page switcher, a command palette (Ctrl K) that reaches every menu
  action, toasts, and two themes - Ink (dark) and Paper (light), and a Reduce motion setting.
- **The stage has a header**: Scene | Game view, Follow playhead, Fit / 75% / 100%, full screen, layout guides and
  a Draft chip. A Properties | Clip | Scene inspector, a timeline header with Snap, Auto-key, + Clip and zoom.
- **Adding objects works like a design tool** ([ADR 0086](../adr/0086-camera-always-first.md) for the camera): a
  grouped tool rail whose insert tools remember the last variant and open a flyout, and an *Add object* popover
  with search, recent objects, categories and drawn glyphs.
- **Audio is a mix**: lanes with waveforms for narration, music, effects and subtitles, a transport strip with a
  master meter, and a Narration card with engine cards, cue states (ready / stale / no sound) and pronunciation
  chips; the tables stay behind a Table toggle.
- **One shape for dialogs**: icon header, one task, primary action last, rows with chips.

### Camera
- **A camera layer** ([ADR 0072](../adr/0072-camera-layer.md)) that pans, zooms and rolls the view by its keys, and
  **works like Unity's 2D camera** ([ADR 0083](../adr/0083-unity-style-camera.md)): a Size, a Background, a layer to
  follow, and a Scene view that draws the camera as a rectangle you drag. It is always the first row of the Layers
  panel and the timeline ([ADR 0086](../adr/0086-camera-always-first.md)). *New Project > Camera tour* shows it.

### Faster and safer exports
- **Parallel exports and GPU encoding** ([ADR 0065](../adr/0065-parallel-export-and-gpu-encoding.md)), an **export
  health report** that finds missing fonts, media and slow Python layers before you render
  ([ADR 0066](../adr/0066-export-health-report.md)), and **resumable exports** that survive a crash or a cancel
  ([ADR 0081](../adr/0081-resumable-exports.md)).

### Edit and understand a project
- **Ripple editing** that opens or closes time and moves what follows, **compound sequences** of clips and keys,
  **editable animation recipes**, **named snapshots**, a **draft preview** while you edit.
- **Beat sheet**, **Explain this moment** (why the frame at the playhead looks like it does), **layout guides**,
  **pinned labels**, and **import a script** as timed subtitles.
- **Code errors say when and where they happened**: a card with *Go to line* and *Go to layer at 0:04.20*, a farm
  chip showing the Python layers rendering, and sliders for declared values.
- **Extract selected layers as one code layer** that draws the same, and **portable bundles** (`.msbundle`) with
  every file a project uses, checked on open.
- **Plugin manifests**: declared metadata, app compatibility and permissions approved once by you.
- **Narration**: a voice reads the subtitles; **chapters** let you edit and re-render one phase.

## Upgrading

- Project files keep `schema_version` 1 and open as they are; the new fields (camera, guides, sequences, pins) are
  omitted unless used.
- A project whose camera was not first is reordered when opened (the camera has no picture of its own, so frames
  do not change).
- Plugins that ship a manifest stay off until you approve them once in the Plugins dialog.

## Known limits

- Equations need a LaTeX installation to be drawn.
- No standalone installer yet; the package needs Python 3.13.
- The camera follows its target exactly (no damping), and its background is one colour for the whole video (not
  keyable). The curve editor draws plain easing for a camera's size.
- Export progress is per job: a parallel export does not show one bar per worker.
- *Extract as code* shows its "same picture" check as not run.
- The guides editor is a dialog, not yet a popover on the stage.
- The audio lanes select and seek; clips are trimmed in the tables or on the timeline.
- Groups carry a transform only: no clips on a group and no nested groups.
- 3D objects are not part of this version.
